# Loan Officer User Guide

Lending, Review, and Collections Operations

Version 1.0

Prepared: 31 March 2026

Audience:

- loan officers
- credit officers
- loan reviewers
- lending supervisors

## 1. Purpose

This guide explains the lending workflows used in CoreBanker and BankInsight, from origination through disbursement, repayment, and loan operations.

## 2. Main Workspaces

Loan officers will mainly use:

- Clients
- Accounts
- Loan Management
- Approvals
- Reporting

## 3. Before Starting a Loan Workflow

Confirm:

- the client record is correct
- KYC readiness is complete for loan origination
- the selected product is appropriate
- any required supporting evidence is available

## 4. Loan Origination

Typical steps:

1. Select the customer.
2. Confirm KYC readiness.
3. Choose the product.
4. Enter principal and supporting reference.
5. Run credit check if needed.
6. Preview the schedule.
7. Submit the application.

## 5. Review and Appraisal

Use the review workflow to:

- inspect application posture
- add appraisal notes
- recommend or confirm readiness for approval

## 6. Approval

Approval users should:

- review application details
- confirm decision notes
- approve only when all required conditions are met

## 7. Disbursement

Disbursement controls may include:

- servicing account selection
- collateral account selection
- client reference confirmation

Only approved facilities should move into disbursement.

## 8. Repayment

Repayment workflows support:

- selecting the active facility
- selecting the debit account
- posting repayment
- reviewing schedule changes

## 9. Schedule Review

The schedule workspace can be used to inspect:

- due dates
- principal and interest mix
- installment totals
- remaining balance
- line status

## 10. Penalty Assessment

Loan operations may support penalty assessment for overdue facilities.

Before applying a penalty:

- confirm the reason
- confirm days-past-due posture
- confirm the applicable rate

## 11. Loan Classification

Classification tools help lending and control users inspect:

- delinquency posture
- BoG tier or quality classification
- provisioning context

## 12. Collections Awareness

Loan officers should monitor:

- arrears posture
- PAR indicators
- repayment patterns
- exception accounts

## 13. Reporting

Useful reporting areas include:

- portfolio posture
- delinquency and PAR
- disbursement trends
- performance summaries

## 14. Best Practices

- Never originate a loan without confirming KYC readiness.
- Review schedule affordability before submission.
- Record meaningful appraisal and approval notes.
- Confirm disbursement details before execution.
- Use reporting and audit tools when investigating exceptions.
